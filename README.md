# Smart Chatbot 🤖

A beginner-friendly chatbot built with Python. It responds to simple messages using rule-based logic and randomized responses.

## Features

- Responds to greetings and simple messages
- Uses keyword matching to identify user input
- Selects random responses
- Runs directly in the terminal
- Supports a simple exit command

## Technologies

- Python 3
- `random` module
- Functions, dictionaries, loops, and conditional logic

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/khalilabdollakh-collab/smart-chatbot.git
cd smart-chatbot
```

### 2. Run the chatbot

```bash
python3 chatbot.py
```

## Example

```text
Welcome to Smart Chatbot!
Type 'bye' to exit.

You: hello
Bot: Hi! How can I help you?

You: bye
Bot: Goodbye! Keep learning Python!
```
